# Homebrew Tap

This is the official Homebrew tap for [SearchDeadCode](https://github.com/KevinDoremy/SearchDeadCode) and other tools by Kevin Doremy.

## Installation

```bash
brew tap KevinDoremy/tap
brew install searchdeadcode
```

## Available Formulas

| Formula | Description |
|---------|-------------|
| [searchdeadcode](https://github.com/KevinDoremy/SearchDeadCode) | Fast CLI tool to detect dead/unused code in Android projects (Kotlin & Java) |

## Updating

```bash
brew update
brew upgrade searchdeadcode
```

## Uninstalling

```bash
brew uninstall searchdeadcode
brew untap KevinDoremy/tap
```
